# IC-RADIO v0.14.0

IC-RADIO is dedicated to local and remote control of the Icom IC-7300 and IC-7300MK2 on Windows. Local mode uses USB CI-V. Remote mode uses the included server on the same PC or another PC on a trusted local network.

## Highlights

- Connect to the radio server from another Windows PC on the LAN. The server displays its LAN addresses and requires the configured password.
- Open the menu on a DX Cluster spot to tune to its frequency or open its callsign page at QRZ. Grouped spots also show country flags when available.

## Download

Extract `IC-RADIO-Windows-x64-v0.14.0.zip` and run `ic-radio.exe`. For remote operation, run `ic-radio-server.exe` on the PC connected to the radio by USB. Keep the `runtime` folder alongside the executables. See the README for LAN setup.
