# IC-RADIO v0.14.1

IC-RADIO is dedicated to local USB CI-V and remote LAN control of the Icom IC-7300 and IC-7300MK2 on Windows.

## Changes

- Select the radio RX input and TX output interactively on the server when multiple matching USB audio devices are found.
- Remember the selected device IDs so the server can distinguish devices with identical names.
- Show the server's radio audio device names in the remote client when available.

## Download

Extract `IC-RADIO-Windows-x64-v0.14.1.zip` and run `ic-radio.exe`. For remote operation, run `ic-radio-server.exe` on the PC connected to the radio by USB. Keep the `runtime` folder alongside the executables.
