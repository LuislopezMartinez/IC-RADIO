# IC-RADIO v0.13.2

IC-RADIO is dedicated to local USB CI-V control and server-based remote control of the Icom IC-7300 and IC-7300MK2. The remote server runs on the same Windows PC.

## Changes

- The BAND selector now uses an amber border and text, and fills in amber when its menu is open.
- Updated the Operation screenshot to show the selector.

## Download

Extract `IC-RADIO-Windows-x64-v0.13.2.zip` and run `ic-radio.exe`. For server mode, use the included `ic-radio-server.exe` on the same PC. Keep the `runtime` folder beside both executables.
