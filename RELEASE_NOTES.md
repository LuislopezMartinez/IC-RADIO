# IC-RADIO v0.13.1

IC-RADIO is dedicated to local USB CI-V control and server-based remote control of the Icom IC-7300 and IC-7300MK2. The remote server runs on the same Windows PC.

## Highlights

- Display the radio's spectrum reference level (REF) in dB when CI-V reports a current value. The trace uses the sweep supplied by the radio, which already incorporates its reference setting.
- Keep the separate TX marker from appearing during ordinary wheel tuning when the confirmed RX and TX frequencies are the same and SPLIT is off.

## Download

Extract `IC-RADIO-Windows-x64-v0.13.1.zip` and run `ic-radio.exe`. For server mode, use the included `ic-radio-server.exe` on the same PC. Keep the `runtime` folder beside both executables.
