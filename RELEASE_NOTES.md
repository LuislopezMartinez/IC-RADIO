# IC-RADIO v0.14.2

IC-RADIO is dedicated to local USB CI-V and remote LAN control of the Icom IC-7300 and IC-7300MK2 on Windows.

## Changes

- Smoothed the TX meters and bar displays.
- The Po needle, header bar and numeric output power readout respond quickly to voice peaks and fall more gradually between them.
- The SWR needle moves smoothly while the numeric readout shows the latest valid measurement.

## Download

Extract `IC-RADIO-Windows-x64-v0.14.2.zip` and run `ic-radio.exe`. For remote operation, run `ic-radio-server.exe` on the PC connected to the radio by USB. Keep the `runtime` folder alongside the executables.
